# Website Profil Kawasan Lereh

Versi terbaru dengan 9 halaman, peta, panduan kakao, dan simulasi usaha interaktif.

## Aktifkan GitHub Pages

1. Buka Settings > Pages.
2. Pada Build and deployment pilih Deploy from a branch.
3. Pilih branch website-lereh dan folder / (root), lalu Save.
4. Tunggu sampai GitHub menampilkan alamat website.

Jika Pages tidak tersedia untuk repositori privat pada paket akun Anda, gunakan repositori publik khusus website atau paket yang mendukung Pages privat. Perubahan visibilitas perlu dipertimbangkan untuk seluruh isi dan riwayat repositori.

Peta dasar memerlukan internet. Angka usaha adalah contoh simulasi, bukan harga terkini atau jaminan keuntungan. Versi pada Sites tetap tersedia.
